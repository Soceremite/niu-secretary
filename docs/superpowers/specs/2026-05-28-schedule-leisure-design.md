# 牛秘书时务局与闲趣集设计规格

日期：2026-05-28
范围：`niu-secretary/schedule/` 与 `niu-secretary/leisure/` 两个静态 Web 子站的视觉与信息架构优化。

## 背景

新闻社和塑形馆已经完成。时务局与闲趣集需要继续归入「牛秘书」品牌矩阵，但不能复用新闻社的民国报刊风格，也不应继续沿用品牌主页的整页黑金暗色控制台。

本轮确认的方向是「私人秘书事务夹」体系：

- 时务局负责安排事务，气质应现代、清爽、可靠。
- 闲趣集负责精选休闲内容，气质应温暖、轻松、有生活感。
- 两者都保留牛秘书的“主动筛选、帮你判断”的管家感，但通过不同色彩和信息组织区分用途。

## 共同设计原则

1. 不做普通工具站首页。页面第一屏要直接呈现核心工作流，而不是只有入口卡片。
2. 不复用新闻社的泛黄旧报纸底色、竖排报刊边线、民国副刊语言。
3. 不使用大面积黑金暗色。金色只作为轻量品牌点缀。
4. 保留“秘书批注”组件，但它必须像签批便笺或工作结论，不能像聊天气泡。
5. 信息密度要适合每天打开：桌面端可一屏看出重点，移动端按优先级自然下落。
6. 继续使用纯静态 HTML/CSS/JS，基于现有 `dist/` 结构迭代，不引入前端框架。

## 时务局设计

### 定位

牛秘书时务局是个人日程与事务管理中心。它不是普通 Calendar，而是“秘书替你把一天排好”的工作桌。

用户打开页面时，首先应该知道：

- 今天最重要的三件事是什么。
- 接下来按时间要做什么。
- 哪些重要日期或生活代办不能忘。
- 长期目标今天应该推进哪一步。

### 视觉方向

采用“现代秘书事务夹”：

- 背景：雾灰绿，表达清爽办公桌。
- 卡片：象牙白，保留纸张和文件夹质感。
- 重点色：墨蓝，用于“要务”、关键提醒和高优先级。
- 点缀色：铜金，用于日期、批注边线、品牌小标签。
- 避免：泛黄旧报纸、深红印章、厚重黑金面板。

建议色板：

- `#e8ece6` 雾灰绿背景
- `#fffefa` 象牙白卡片
- `#243746` 墨蓝要务
- `#6f857a` 灰绿辅助
- `#d0b37c` 铜金点缀
- `#59676b` 正文辅助文字

### 首页结构

第一屏采用两列布局：

1. 顶部身份区
   - 标题：`牛秘书时务局`
   - 副文案：强调“排班、提醒、代办、目标收进同一个事务夹”
   - 右侧使用圆角日期牌，而不是报纸印章

2. 左侧主区：`今日排班`
   - 时间轴展示当天安排。
   - 每条记录包含时间、事项名、简短说明、分类标签。
   - “要务”使用墨蓝高亮。

3. 右侧上方：`秘书提醒`
   - 控制在 3 条以内。
   - 内容不是系统通知，而是优先级判断。
   - 示例：今天只抓三件事、重要日期提前露出、长期目标拆到今天。

4. 右侧下方：`事务抽屉`
   - 展示六个模块入口：日程核心、重要日期、生活代办、目标追踪、阅读学习、出行助手。
   - 采用轻量胶囊标签或文件夹标签。

5. 底部：`今日批注`
   - 替代旧版“管家口吻”黑底横条。
   - 样式为浅色便笺，左侧铜金竖线。
   - 文案短、克制、像秘书签批。
   - 可带两个轻按钮：生成明日预排、收进复盘。

### 交互重点

- 今日排班应支持按当前时间突出下一项。
- 模块入口不应喧宾夺主，首页先服务“今天怎么过”。
- 移动端顺序：身份区、今日排班、秘书提醒、事务抽屉、今日批注。
- 所有文本要避免按钮内换行溢出。

## 闲趣集设计

### 定位

牛秘书闲趣集是个人休闲推荐中心。它不做娱乐网站首页，也不做新闻副刊，而是“今晚我该看什么、听什么、读什么”的私人推荐夹。

用户打开页面时，首先应该知道：

- 今晚最适合的一个主推荐是什么。
- 为什么这个推荐适合今天。
- 如果不想看这个，可以换成影视、音乐、播客或阅读。
- 牛秘书记住了哪些口味偏好。

### 视觉方向

采用“私人秘书的休闲推荐夹”：

- 背景：象牙白和轻暖灰，区别于时务局的办公绿。
- 主点缀：茶金，表达休闲、温暖。
- 辅助色：灰蓝，用于推荐理由、轻按钮和休闲批注。
- 内容卡片可以有更柔和的渐变封面，但不使用真实影视海报作为必需资产。

建议色板：

- `#f1eee7` 温暖背景
- `#fffdf7` 推荐卡片
- `#c9975f` 茶金重点
- `#66848e` 灰蓝辅助
- `#243746` 深色文字/少量强调
- `#676157` 正文辅助文字

### 首页结构

第一屏采用“主推荐 + 候选列表”布局：

1. 顶部身份区
   - 标题：`牛秘书闲趣集`
   - 副文案：强调“按时间、心情和口味给少量精选”
   - 右侧放 `口味档案` 小卡，展示偏好标签和匹配进度

2. 左侧主区：`今晚首推`
   - 一个主推荐卡片。
   - 包含封面视觉、推荐标题、推荐理由、适合场景。
   - 推荐理由应解释“为什么今天适合”，而不是只列内容简介。

3. 右侧：`今日候选`
   - 四类候选：影视、音乐、播客、阅读。
   - 每类展示名称、适合场景、预计时长。
   - 每项保持短句，不做信息堆叠。

4. 底部：`闲趣批注`
   - 样式与时务局的批注组件一致，但左侧强调色用灰蓝。
   - 示例文案：今天适合低负担内容，不追热点，不刷长榜。
   - 可带两个轻按钮：换一组、加入今晚。

### 交互重点

- 推荐结果要少而精，避免瀑布流和无限滚动。
- 操作优先级：加入今晚、换一组、收藏、跳过。
- 口味档案应该是“可感知的偏好摘要”，不是复杂设置页。
- 移动端顺序：身份区、口味档案、今晚首推、今日候选、闲趣批注。

## 与现有项目的关系

现有目录：

- `/home/ubuntu/.openclaw/workspace/niu-secretary/schedule/`
- `/home/ubuntu/.openclaw/workspace/niu-secretary/leisure/`

两者已经有 `dist/index.html`、`logo.png` 和 JavaScript 数据文件。实现时应在现有静态站基础上替换首页视觉与信息结构，并保留可用的数据层。

需要同步更新的文档：

- `niu-secretary/SKILL.md` 中功能矩阵的访问路径与视觉描述。
- `schedule/SKILL.md` 中“视觉继承品牌主页 dark luxury 黑金配色”的描述。
- `leisure/SKILL.md` 中“视觉继承品牌主页 dark luxury 黑金配色”的描述。

部署路径需要在实现前再次核对。品牌主页当前对外为 `/niu-secretary/`，因此两个子站建议落在：

- `/niu-secretary/schedule/`
- `/niu-secretary/leisure/`

如果现有 nginx 仍使用 `/home/schedule/` 或 `/home/leisure/`，实现计划中需要包含路由修正。

## 验收标准

1. 时务局首页不再呈现黑金控制台或新闻社报刊感。
2. 闲趣集首页不再呈现黑金控制台或新闻副刊感。
3. 两个页面都能在第一屏传达各自用途。
4. 两个页面共享“私人秘书事务夹”体系，但颜色、节奏、内容气质明显区分。
5. 桌面端和移动端无文字溢出、遮挡或卡片底部不齐的问题。
6. 保留现有静态部署方式，页面可通过 nginx 正常访问。
