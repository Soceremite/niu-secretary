基于个人口味偏好的休闲内容推荐中心。不靠算法投喂，而是由 AI 精心筛选——像一位了解你品味的朋友，每周给你推荐值得花时间的好内容。

**牛秘书放映厅** — 寓意私人的、高品质的、沉浸式的内容鉴赏空间。超越字面的"放映"，涵盖电影、剧集、音乐、播客等全品类休闲内容。

## 推荐机制

### 数据流

```
AI cron (每周 2-3 次)
  ↓ 读取口味档案 + 当前热点
  ↓ AI 生成个性化推荐
  ↓ 写入 data/*.json
  ↓ 页面加载 JSON 渲染
  ↓ 用户评分/收藏反馈
  ↓ 更新口味档案
  ↓ 下次推荐更精准
```

### 偏好标签体系

```
类型: 科幻 / 悬疑 / 喜剧 / 文艺 / 动画 / 纪录片 …
地区: 大陆 / 香港 / 日韩 / 欧美 / 其他
年代: 经典(2000前) / 近十年 / 近年 / 新片
心情: 放松 / 热血 / 沉思 / 治愈 / 刺激
时长: 短片 / 电影 / 剧集
```

### 推荐卡片设计

每张推荐卡片包含：
- 封面/海报（若有资源）
- 标题 + 原名
- 评分（AI 预估匹配度 + 公开评分）
- 推荐理由（一句 AI 生成的推荐语）
- 操作：👍 喜欢 | 👎 跳过 | ⭐ 收藏 | 📌 已看/想看

## Cron 任务规划

| 任务 | 频率 | 内容 |
|------|------|------|
| 影视推荐更新 | 每周一、四 | 生成本周热门 + 个性化推荐 |
| 音乐推荐更新 | 每周三 | 新专辑 + 心情歌单 |
| 播客推荐更新 | 每周五 | 周末通勤播客精选 |

## 交互设计要点

- 推荐卡片横向滑动（移动端友好，像电影选片）
- 海报悬停放大 + 推荐语渐显
- "今日推荐"区域金色强调，突出精选感
- 口味档案用标签云展示，可点击编辑
- 收藏页面用封面网格排列，杂志感
